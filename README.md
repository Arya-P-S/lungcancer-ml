# 🧠 Lung Cancer Prediction using Machine Learning

## 📌 Project Overview
This project predicts whether a person has lung cancer using Machine Learning techniques based on patient survey data.  
The model is trained using the Random Forest algorithm and includes visualization for better analysis and understanding.

---

# 🚀 Features
✅ Data preprocessing  
✅ Label encoding  
✅ Machine Learning model training  
✅ Prediction system  
✅ Accuracy evaluation  
✅ Confusion matrix visualization  
✅ Feature importance graph  
✅ Dataset distribution graph  

---

# 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

# 🤖 Machine Learning Algorithm
- Random Forest Classifier

---

# 📊 Dataset
Dataset used: **Survey Lung Cancer Dataset**

### Dataset Features:
- Gender
- Age
- Smoking
- Yellow Fingers
- Anxiety
- Peer Pressure
- Chronic Disease
- Fatigue
- Allergy
- Wheezing
- Alcohol Consuming
- Coughing
- Shortness of Breath
- Swallowing Difficulty
- Chest Pain

### Target:
- `LUNG_CANCER`
